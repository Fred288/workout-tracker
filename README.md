# workout-tracker

Private Strong-style workout tracker as a PWA. See PLAN.md.

## Endurance and triathlon

The "Ausdauer" area (see ENDURANCE-PLAN.md) adds goals and rule-based training plans for 5 km to marathon and sprint/olympic triathlon, a run/swim/bike timer, zones from pace, heart rate or power, a load model (fitness, fatigue, form), plan adaptation and activity import (GPX, TCX, FIT). Everything runs in the browser, no server, no AI, no GPS tracking. It is part of the normal backup (Settings) and works offline. The guided tour (start page) covers it and must be updated with every new feature.
